# zomato-data-analysis
# 🍽️ Zomato Data Analysis

## 📌 Project Overview

This project focuses on **Exploratory Data Analysis (EDA)** of Zomato restaurant data using Python.

The objective is to understand restaurant trends, customer preferences, ratings, votes, approximate spending, and online ordering behavior through data analysis and visualization.

---

## 🛠️ Technologies Used

* 🐍 Python
* 🐼 Pandas
* 🔢 NumPy
* 📊 Matplotlib
* 📈 Seaborn
* 📓 Jupyter Notebook

---

## 📂 Dataset

The dataset contains information about Zomato restaurants, including:

* Restaurant Name
* Restaurant Type
* Online Order Availability
* Table Booking
* Ratings
* Number of Votes
* Approximate Cost
* Location
* Listed In Type

---

## 🔍 Analysis Performed

The following analyses were performed:

### 1. Restaurant Type Analysis

Analyzed the distribution of different restaurant types and identified the most common categories.

### 2. Votes Analysis

Compared customer votes across different restaurant categories.

### 3. Rating Analysis

Studied the distribution of restaurant ratings to understand overall customer satisfaction.

### 4. Approximate Cost Analysis

Analyzed the approximate cost for two people and identified common spending patterns.

### 5. Online vs Offline Orders

Compared ratings and ordering behavior between restaurants offering online ordering and those without it.

### 6. Heatmap Analysis

Used a heatmap to analyze the relationship between restaurant types and online ordering availability.

---

## 📊 Key Insights

* Dining restaurants represent a significant portion of the dataset.
* Dining restaurants received a high number of customer votes.
* Most restaurants have ratings in the mid-to-high range.
* Restaurants with an approximate cost of around ₹300 are commonly preferred.
* Online ordering availability varies across different restaurant categories.
